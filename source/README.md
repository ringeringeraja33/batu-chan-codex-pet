- 图集构建入口：`python scripts/build_assets.py`

构建脚本会自动移除洋红色背景、抑制边缘色溢，并生成透明 RGBA WebP 图集。

当前母版从零重绘，不复用多轮编辑后退化的前景像素，并依据用户提供的肖像校准拔都的尖俏少年脸型、上挑琥珀色眼睛、细窄小瞳、黑色齐颌短发和自信神态。九格中的头脸直径、躯干厚度与服装比例统一，构建时固定使用同一个源图缩放率，跑步、挥手、坐姿和展开地图等外伸元素不再导致角色主体忽大忽小。刘海统一向右斜扫；头发下方明确绘制左右两个蒙古族环形麻花辫，采用贴近脸颊的窄长自然 U/水滴轮廓，整个辫圈向头部与胸前中线内移约一个辫宽并保留中央空隙。军帽采用包裹头部的下垂毛圈，前檐中心位于额头上方，两侧从太阳穴明显向下转折到耳上缘附近；上方保持低矮对称浅圆帽冠。帽面恰有两条浅色弧纹，并共同汇聚到同一银色帽缨结；黑红帽缨从结点短暂上扬后形成较低、宽缓、柔软的后掠弧，各缨条自然分层下垂，末梢按最终要求缩短并将单条宽度收细约 15%。两张地图均重新绘制为较粗、较深且留白清楚的路线、区域边界、山形与地标线稿；下方中间卷轴的展开页从卷筒最外层连续伸出。服装继续采用黑色高领披肩军袍、浅金滚边与胸前圆徽。待机和挥手使用稳定静态帧；任务思考/工作与指针注视帧均锁定读地图姿势，避免注视覆盖导致姿态跳回站立。悬停状态复用落地挥手，不会跳起。
